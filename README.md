# How Many Tabs Do You Have Open?

The entry is the number **2**: one tab for the thing you are actually doing, one tab for the thing you opened to avoid doing it. Against a field of tab hoarders, two tabs is far lower than anyone guesses — yet completely believable as an honest, lived-in count, the smallest number a real browser user can truthfully give short of the single-tab monk.

`main.py` writes the digit to `/output/entry.txt` (or `$OUTPUT_PATH` when set), deterministically, stdlib only.
